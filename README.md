# JEJU WAVE 济州浪

**말이 안 통해도, 배를 놓칠 걱정 없이.**
강정항에 내린 외국인 크루즈 관광객을 위한 다국어 테마 택시 웹앱이에요. 앱이 기사와 승객 사이에서 **통역사 겸 타임키퍼**가 됩니다.

> 제주대학교 관광경영학과 캡스톤디자인 (기업연계형, 연계 기관: 제주관광공사)
> 팀 제주웨이브 · 주제: 강정항 외국인 크루즈 테마 관광 시스템 구축
> 같은 팀장의 이전 프로젝트 **Golden Hour**(https://github.com/speech064/project)와 같은 기술 구조로 만들었어요.

이 문서 하나만 읽어도 프로젝트의 배경, 근거 자료, 사용 API, 구조, 실행 방법, 남은 과제를 모두 알 수 있게 정리했어요. Claude Code 같은 코딩 도구에 넘길 때도 이 문서를 먼저 읽히면 됩니다 (`CLAUDE.md`에 작업 규칙 요약).

### 2-2. 관광객의 두 가지 공포

- **낙오:** 배를 놓칠까 봐 멀리 못 가고 면세점만 들렀다가 돌아가요. 그래서 서귀포 상권에 돈이 떨어지지 않아요.
- **요금:** 미터 요금이 얼마 나올지, 기사가 돌아가는 건 아닌지 몰라요. 이 빈틈을 불법 승합차 영업이 파고들어요 [R7].

## 3. 핵심 아이디어와 차별점

### 3-1. "외국어 기사만 매칭" ✕ → "앱이 세 번째 동승자" ○

크루즈 1척에서 2,000~3,000명이 내리고 그중 56.6%가 택시를 주로 탑니다. 외국어 가능 기사만으로는 수요를 감당할 수 없어요(공급 병목). 그래서 **앱이 통역사 겸 타임키퍼**가 되어 **한국어만 하는 서귀포 일반 택시 기사도 누구나 운행**할 수 있게 설계했어요.

- 기본: 일반 기사 + 앱 통역(소통 카드, 음성, 자유 대화 번역)
- ⭐ 프리미엄: 손님 언어를 하는 기사(글로벌 택시회)는 **우선 배차**되고 가이드 해설까지 제공

### 3-2. 우버·카카오T와의 차이

| | 우버 / 카카오T | JEJU WAVE |
|---|---|---|
| 이동 방식 | A → B 단순 이동 | **시간 제약형 순환 관광** (항구 → 명소 1~4곳 → 항구) |
| 배 출항 시간 | 모름 | 승선 마감 기준으로 역산, 실시간 3단계 판정 |
| 늦어질 때 | 승객이 알아서 | 못 갈 경유지 **자동 삭제** + 양쪽 화면 동시 알림 |
| 언어 | 앱 화면만 번역 | 차 안 대화 통역 + 음성 + 오프라인 소통 카드 |
| 요금 | 미터 / 호출 시 예상 | 코스 전체 예상 요금 **사전 고지** (이동 + 대기) |
| 근거리 손님 | 기피 문의 발생 | 코스 단위 예약이라 거리와 무관하게 배차 |
| 지역 상권 | — | 올레시장 중심 코스·웰컴키트로 서귀포 소비 유도 |

### 3-3. 1학기 피드백에 대한 답

1학기 발표 때 받은 지적은 **"직접 개발한 것이 없다"**였어요. 이번에는 아이디어와 목업 대신 **배포 가능한 웹앱, 단위 테스트, 실시간 2화면 시연**으로 답합니다.

| 1학기 | 지금 |
|---|---|
| 앱 화면 틀(목업) | 실제 웹앱, QR로 바로 사용, 4개 언어 |
| '자동 코스 추천' 아이디어 | 안내소 데이터 기반 추천 코스 + 지도 + 예상 요금, 단위 테스트 13개 |
| '외국어 기사 매칭' | 누구나 운행 + 앱 통역, 언어 가능 기사는 우선 배차 |
| '실시간 통역·가이드' 설명 | 차 안 통역 채팅 + Claude AI 가이드 |
| '무료 기념사진' | 디지털 기념엽서 (济州浪 프레임 PNG) |
| 기대효과 문장 | 관리자 대시보드 (언어·테마별 이용, 웰컴키트 전달 수) |

## 5. 핵심 로직 (규칙과 계산식)

모든 계산은 `shared/`에 있고 **화면·서버·AI가 같은 함수**를 씁니다. 그래서 세 곳의 숫자가 서로 다르게 나오지 않아요.

### 5-1. 정시 복귀 판정 (`shared/route.js` → `checkReturnSafety` = `judgeReturn`, 규칙은 `shared/port.js` → `RULES`)

```
남은 여유 = (승선 마감 − 지금) − (항구까지 택시 시간 + 터미널 수속 버퍼 40분)
🟢 좋음 ≥ 60분  ·  🟡 주의 30~60분(서둘러 이동)  ·  🔴 위험 < 30분(즉시 복귀 + 남은 경유지 자동 삭제)
```

한희섭 교수 자문의 '시간 관리 및 정시 복귀 보장' 포지셔닝을 구현한 부분이에요.

### 5-2. 코스 검증·자동 단축

- `checkPlan`: 정해진 정류장 순서로 도착·출발 시각, 항구 복귀 시각, 남는 시간, 예상 요금을 계산해요. 카카오에서 받은 실제 구간 시간(`legs`)이 있으면 그 값을 써요.
- `fitToShip`: 내 배 시간에 안 되면 **뒤쪽 정류장부터 빼서** 되는 버전을 돌려줘요.
- `trimRemaining`: 운행 중 타임키퍼가 남은 경유지 중 못 갈 곳을 골라내요.
- `planCourse`: 테마만 주면 가까운 순으로 코스를 짜요 (AI 도구에서 추천 코스가 맞지 않을 때만 사용).

### 5-3. 이동 시간

- 1순위: 카카오모빌리티 다중 경유지 길찾기의 실제 구간 시간 + 승하차 5분
- 대체: 어림 계산 = 직선거리 × 1.35(도로 굽음) ÷ 시속 35km + 5분 (`estimateDrive`)
- 카카오 키가 없거나 장애가 나면 자동으로 어림 계산으로 바뀌어요 (무중단 폴백).

### 5-4. 예상 요금 (`shared/fare.js`)

```
예상 요금 = Σ 구간별 미터 요금 + 명소 대기 시간 요금
구간 미터 요금 = 기본 4,300원(2km) + 126m당 100원, 신호·저속 +10%
대기 요금 = 31초당 100원 ≈ 시간당 11,600원
```

- 요율은 언론 보도 기준이에요 (2023-11 거리·시간 요율, 2024-07 기본요금) [R8]. **운영 전 제주도 고시로 재확인이 필요해요.**
- 대형(승합) 택시 요율은 아직 반영하지 않았어요.

### 5-6. 한국인에게 묻기 · 편의점 안내

- **왜:** 관광객 앱은 장소를 번역된 이름으로 보여 줘서, 현지인에게 물어봐도 알아보지 못해요. 크루즈 안내소에도 '지도설명' 문의가 많아요 (강정항 영어권 7%·중국어권 4%, 제주항 일본어권 15%·중국어권 10%) [R1].
- **장소 검색:** `server/place.js` → 카카오 로컬 키워드 검색(제주 중심 반경 20km). 키가 없으면 앱 명소 목록(4개 언어 이름)에서만 찾고, 못 찾으면 입력한 글 그대로 카드를 만들어요.
- **QR:** 좌표가 있으면 `map.kakao.com/link/to/{이름},{위도},{경도}`(길찾기), 없으면 `map.kakao.com/link/search/{주소|이름}`.
- **편의점 데이터:** `shared/stores.js` (`STORE_ITEMS`, `ANYWHERE`, `SOURCES`, `ASOF`). PB(자체 브랜드)는 그 체인에서만 판매. **상품은 자주 바뀌므로 기준일(ASOF) 이후 단종 가능**하고, 화면에도 기준일과 출처를 보여 줘요. 근거 기사는 외국인 구매 순위(택스리펀드·국적별 분석)이고, 중국 SNS(샤오홍슈 등) 인기 순위를 직접 집계한 자료는 아니에요.

### 5-7. 3D 코스 시뮬레이터 (`src/pages/Sim.jsx`, `src/three/jejuSim.js`)

- **외부 3D 모델·지도 타일·API 키 없이** Three.js 내장 도구만 사용: 정점 고도를 바꾼 PlaneGeometry 지형(해안선 다각형 24점 + 한라산 가우시안, 높이 5배 과장), ShaderMaterial 바다, CatmullRomCurve3 + TubeGeometry(해안도로·코스 아치), 도형 조합 크루즈선·택시, CSS2DRenderer 배지(한·중·일 글자 깨짐 방지), OrbitControls + 카메라 lerp.
- 좌표 변환: 중심(33.37, 126.55) 기준, 경도 1도 ≈ 92.9km · 위도 1도 ≈ 111km, 1 단위 = 10km (`toXZ`).
- [📲 이 코스로 택시 예약] 버튼: 경유지·체류 시간을 그대로 `/ride`로 넘겨요 (강정항 출발일 때만).
- **계산은 앱과 같은 함수** (사용자 결정: 앱 기준 통일): 택시 = 직선 × 1.35 ÷ 35km/h + 5분, 버스 = 직선 × 1.35 ÷ 20km/h + 대기 15분(`estimateBus`), 요금 = `shared/fare.js`, 판정 = `checkPlan`(승선 마감 40분 전까지 항구 도착, 🟢 여유 30분 이상 · 🟡 0~30분 · 🔴 부족 → `fitToShip`으로 뺄 곳 제안).
- 출발 항구는 강정항·제주항 중 선택. 경유지는 최대 6곳. 해안선 다각형과 추가 명소(중문 지정면세점·카멜리아힐·성산일출봉·공항·제주항) 좌표는 **어림값**.

| `list_nearby_places` | 비짓제주 주변 장소 |

**카카오** (developers.kakao.com → 내 애플리케이션 → 앱 하나에서 키 두 개)
- REST API 키 → `KAKAO_REST_KEY` (서버 전용). 앱 설정에서 **카카오내비 API 사용을 켜야** 해요.
  - 다중 경유지: `POST https://apis-navi.kakaomobility.com/v1/waypoints/directions` (origin, destination, waypoints, priority=RECOMMEND)
  - 자동차 길찾기: `GET https://apis-navi.kakaomobility.com/v1/directions?origin=lng,lat&destination=lng,lat&priority=TIME`
  - 로컬 키워드 검색: `GET https://dapi.kakao.com/v2/local/search/keyword.json?query=…&x=126.55&y=33.38&radius=20000` (1시간 캐시)
  - 헤더: `Authorization: KakaoAK {REST 키}`. 길찾기 결과는 10분 캐시해요.
- JavaScript 키 → `VITE_KAKAO_JS_KEY` (브라우저용 공개 키). 앱 설정 → 플랫폼 → **Web에 `http://localhost:5173`과 Vercel 주소를 등록**해야 지도가 떠요.

**Open-Meteo**: `GET https://api.open-meteo.com/v1/forecast` (강정항 좌표, hourly 기온·강수확률·날씨코드·풍속, timezone Asia/Seoul). 키 없음, 5분 캐시(실패 시 30분 이내 예전 값 사용).

**비짓제주**: `GET https://api.visitjeju.net/vsjApi/contents/searchList?apiKey=…&locale=kr&page=N`. **공공데이터포털 키가 아니라** visitjeju.net/kr/visitjejuapi에서 신청해 메일로 받는 키예요 (Golden Hour 키 재사용 가능). 좌표 검색이 없어서 전체(약 6천 건)를 받아 1시간 보관하고, 서버에서 거리로 걸러요. 끝난 축제·행사는 `server/freshness.js` 규칙으로 빼요.

**Supabase**: anon 키로 브라우저에서 직접 읽고 써요. 서버 함수(`server/ships.js`)도 같은 환경변수로 REST 조회해요. `bookings`, `ride_messages` 표는 Realtime 구독해요.

## 13. 작업 이력과 의사결정

1. **출발점:** Golden Hour(제주 IP × 공공데이터 × AI) 구조를 분석하고, 제주웨이브를 같은 스택으로 재구현하기로 결정.
2. **1학기 피드백 대응:** "직접 개발 없음" → 작동하는 웹앱 + 테스트 + 실시간 시연. 데모 요소는 정직하게 표시.
3. **포지셔닝 전환:** "외국어 기사 매칭" → "플랫폼이 통역사 겸 타임키퍼". 운전 중 안전 때문에 기사 쪽은 큰 버튼 소통 카드 + 음성 중심, 자유 대화는 정차 중에.
4. **심사위원 공격 포인트 반영:** 공급 병목(누구나 운행), 요금(사전 고지), 우버 차별점(비교표), 기능 과다(80/20 배분), 판정 규칙 강화(버퍼 40분, 위험 시 경유지 자동 삭제).
5. **WAY:ON 벤치마킹:** 순환 동선 지도, 경비 시각화, 단계형 입력을 참고. 커뮤니티·일반 번역·로그인은 크루즈 승객에게 맞지 않아 제외.
6. **추천 코스:** 짧은 성향 검사 대신 **실제 안내소 데이터 기반 추천 코스**를 직접 제시 (R1).
7. **지도·이동 시간:** 카카오로 통일 (지도 SDK + 모빌리티 길찾기). 키가 없으면 OSM + 어림 계산.
8. **2025 실태조사 반영:** 문제 수치 교체(언어 3.62/3.95의 연도 정리, 택시 31.6% → 56.6%), 대형 택시 안내 추가 (R2).
9. **현장 관찰 반영 (R11):** 번역된 이름으론 길을 물을 수 없다 → 한글 원문 + 카카오맵 QR '한국인에게 묻기'. 편의점 전용 라면을 마트에서 찾는다 → 편의점별 PB 상품 안내 (R10). 하단 탭의 엽서 자리를 '묻기'로 교체.
10. **3D 코스 시뮬레이터:** Three.js 내장 도구만으로 입체 제주·코스·택시를 그리고, 계산은 앱 기준(버퍼 40분·×1.35·35km/h)으로 통일, 버스 비교만 추가.
